Dead Air Privacy Policy
Last Updated: November 22, 2026

Dead Air does not collect, store, or share any personal information.

The game does not collect:
- Names
- Email addresses
- Account information
- IP addresses
- Wi-Fi information
- Location data
- Photos, videos, or files
You do not need to create an account or provide any personal information
to play Dead Air.

The game is designed to work without collecting player data.

If this Privacy Policy changes in the future, the updated version will
be posted on this GitHub repository.

If you have any questions, please contact the developer through GitHub.

By downloading or playing Dead Air, you agree to this Privacy Policy
